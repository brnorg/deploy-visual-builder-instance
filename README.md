# Deploy Visual Builder Instance

Este repositório contém a configuração necessária para realizar o deploy de uma instância do Visual Builder utilizando uma esteira automatizada.

## Estrutura da Esteira

A esteira de deploy foi configurada para realizar as seguintes etapas:
1. **Build**: Compilação do código-fonte e preparação dos artefatos.
2. **Testes**: Execução de testes automatizados para garantir a qualidade do código.
3. **Deploy**: Publicação da aplicação na instância configurada.
